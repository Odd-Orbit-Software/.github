# Security

Thanks for taking the time to look. If you've found a security problem in any Odd Orbit project, please tell us privately first so we can fix it before it's public.

## How to report

- **On GitHub (preferred):** open the project's **Security** tab and choose **Report a vulnerability**. Only we can see the report.
- **By email:** write to [hello@oddorbit.software](mailto:hello@oddorbit.software) with "Security" in the subject.

Please don't open a public issue for a security problem.

It helps to include:

- which project and version (or commit) you were using, and where it was running (for example a webOS TV, Linux, or a Raspberry Pi);
- what the problem is and what someone could do with it;
- the steps to reproduce it, or a proof of concept.

## What happens next

We're a small studio, so we can't promise a fixed response time, but we read every report. We'll confirm we've received it, keep you posted while we work on a fix, and credit you in the release notes if you'd like.

## What's covered

The latest release of each project in this organisation. Older releases get fixes only if the problem can't be avoided by updating.

Projects that run on your own hardware or talk to your own servers (Vox Folio and your Audiobookshelf server, Paperphase on your Pi, Luna Engine game files) are where we most want to hear about problems.
