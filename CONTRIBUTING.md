# Contributing

Thanks for wanting to help. Odd Orbit is a small studio, so here's how it works across our projects. A project's own `CONTRIBUTING.md`, if it has one, takes priority over this page.

## Issues are welcome

Bug reports and feature ideas are the most useful thing you can send. Use the issue forms on the project's **Issues** tab: they ask for the version and the platform you're on, which is usually what we need first.

For security problems, please follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

## Pull requests: ask first

Please open an issue, or comment on an existing one, before you start on a pull request. Our projects have different licences, and some of them aren't open source:

| Project | Licence |
| --- | --- |
| Sudoku | 0BSD |
| Luna Engine | Source available (PolyForm Noncommercial, with a permission for commercial games) |
| Vox Folio | Source public, no open-source licence |
| Paperphase | Not yet chosen |

So we need to agree how a change will be accepted before you put time into it. Small fixes such as typos and broken links are fine to send straight away.

## When you do send one

- Keep it to one change, and say what it fixes or adds.
- Run the project's tests, and add tests for new behaviour.
- Update the docs if you change how something works.
- Make sure CI passes.

## Want something built?

If you'd like us to build something for you, the [contact page](https://oddorbit.software/contact/) is the place, not an issue.
